# 7X FDE AI Shipment Frontend

See the root `README.md` for the full setup, demo script and tests.

```bash
npm install
npm run dev          # http://localhost:5173 (backend expected at http://127.0.0.1:8000)
```

Override the backend URL with `VITE_API_BASE=http://host:port npm run dev`.

All customer-facing text (English + Arabic) lives in `src/i18n.js`.
