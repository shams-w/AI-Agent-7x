# Data Audit: 7X FDE Shipment Dataset

**Scope:** all **866** records in `data/FDE_Assignment_Shipment_Dataset.xlsx` (raw) and `outputs/FDE_Assignment_Shipment_Dataset_AI_Cleaned.xlsx` (reference), checked against the project's existing rules.
**Mode:** the audit is read-only (`python audit/run_data_audit.py` writes only `audit/data_audit_records.csv` and `audit/data_audit_summary.json`).
**Last run:** 2026-10-03, after the validation-gap fixes (placeholder address, safe date formats, UAE mobile validation).

> **Principle:** the system deterministically normalizes safe cases and routes ambiguous or operationally unsafe data to customer input or human review rather than guessing.

## Data integrity

- **Raw dataset:** byte-identical to the originally delivered file (SHA-256 `8160d520…4137`). It is never written.
- **Cleaned dataset:** regenerated by the existing Data Agent. Compared with the previous version, it changed only by:
  - **34 dates converted to ISO** (21 shipment, 13 last-attempt; 27 records). Each was in an unambiguous `D Mon YYYY` or Excel-serial format, and each conversion is recorded in `AI_Notes`.
  - **`AI_Action`/`AI_Notes` updated on 21 records** to reflect those conversions and the newly detected placeholder addresses (`same as before`, `.`).
- **Not changed:** names, phones, addresses, statuses, attempts, COD and weight are identical. The 200 decimal COD values and 842 decimal weights are unchanged.

## 6. Recommended handling

1. **Ops data correction in the source system:**
   - merge the 18 conflicting duplicates
   - correct the 10 weights, 25 ambiguous dates, 18 date sequences and 15 Delivered-with-0-attempts rows
   - remove the 8 test records
   - then re-run `python -m backend.data_agent`
2. **Keep as-is:**
   - customer-input flows (mobile, address)
   - simulated internal review for weight and Out-for-Delivery-without-address
   - hidden sensitive notes
   - the `Undelivered → Failed Delivery` mapping (only with attempts ≥ 1)
3. **Data owner decision:** confirm whether 051/053/057/059 should join the MVP prefix list for new numbers.
